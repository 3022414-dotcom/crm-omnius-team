## Summary

Add clipboard image paste to the Notes tab (`NotesTab.jsx`): intercept `onPaste` events on the textarea, upload the image as an attachment via the existing `POST /api/v1/attachments` endpoint, append a markdown reference to the note content, and render inline images in view mode by parsing `![image](url)` references with a custom regex. One minimal backend change: add a `url` field to the `createAttachment` response so the frontend can reference the static file path without an additional API call.

## Implementation Notes

### Backend change (attachmentsController.js)

In `createAttachment`, after computing `relPath` (already done for file storage), add to the `res.status(201).json(...)` call:
```js
url: '/' + relPath,
```

`relPath` is the path relative to the project root, e.g., `uploads/accounts/uuid/uuid_file.png`. Prepending `/` makes it a browser-accessible path served by `app.use('/uploads', express.static(...))`.

### Frontend change (NotesTab.jsx)

Three additions to the existing component:

1. **`pendingImages` state**: `useState([])` — tracks uploads in the current editing session. Each entry: `{ localId, status: 'uploading'|'done'|'error', url?, errorMessage? }`.

2. **`handlePaste` function**: Attached to `<textarea onPaste={handlePaste}>`. Detects image in `event.clipboardData.items`, calls `uploadAttachment(formData)`, updates `pendingImages` state, appends `![image](url)\n` to the note text on success.

3. **`renderNoteContent` function**: Splits note content on `![alt](url)` regex matches. Renders text segments as `<span className="whitespace-pre-wrap">` and image matches as `<img className="max-w-full rounded...">`. Used only in view mode (not inside the textarea).

See `contracts/ui.md` for the exact logic of all three additions.
